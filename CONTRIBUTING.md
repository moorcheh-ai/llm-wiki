# Contributing

Contributions are welcome — especially:

- **New cookbook examples** — show how you've used LLM Wiki + Moorcheh for a specific domain (research, product, competitive intel, etc.)
- **Schema improvements** — better page types, smarter ingest workflows, new lint checks
- **Obsidian config** — better graph view settings, useful plugins, hotkey configurations
- **Agent compatibility** — notes on using this with specific agents (Cursor, Windsurf, Gemini CLI, etc.)
- **Bug reports** — if the CLAUDE.md/AGENTS.md instructions produce inconsistent agent behavior

## How to Contribute

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-improvement`
3. Make your changes
4. Open a pull request with a clear description of what you changed and why

## Schema Changes

If you modify `CLAUDE.md` or `AGENTS.md`, please test the changes with at least one full ingest-query-lint cycle before submitting a PR.

## Questions

Open an issue or reach out at [moorcheh.ai](https://moorcheh.ai).
